# How-To Backend starten
**mit IntelliJ** \
In der Datei `./src/main/kotlin/Main.kt` die Main-Funktion starten \
**In der Command Line** \
Die schon gebuildete Jar `out/artifacts/film_emulation_main_jar/film-emulation.main.jar` starten:
> java -jar ./out/artifacts/film_emulation_main_jar/film-emulation.main.jar

# How-To Frontend starten (npm)
> npm run dev
